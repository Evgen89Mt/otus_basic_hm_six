# otus_basic_hm_six

Задание реализация контейнеров.

1. Подзадача разработать аналог контейнера vector. 
    Принципт хранения данных - динамический (работает с кучей, нужно грамотно освобождать ресурсы). Он последовательный, т.е. память устроена, как в массиве "единый блок", можно использовать "адресную арифметику".

    Преимущества:   - быстрый доступ к памяти оператором [].
    Недостатки:     - медленный поиск(O(n)).  
    ------------------------------------------------------------------------------------------------------------------------------------------------
    Реализовано в векторе:

        Конструкторы:
            - Пустой;
            - С выделением буфера памяти capacity;
            - Копирующий;
            - Перемещающий;

        Деструктор с полной очисткой.

        Итераторы:
            - begin (указатель на начало массива);
            - end (указатель на последний элемент массива);
            - const cbegin const;
            - const cend const;

        Методы:
            - Оператор присваивания копированием;
            - Оператор присваивания перемещением;
            - Оператор доступа к ячейки памяти;
            - Оператор доступа к ячейки памяти констовый;

            - front (доступ к первой ячейки);
            - const front const;
            - back (доступ к последней ячейки);
            - const back const;
            - data (ссылку на начало массива (вектора));
            - const data const;
            - size const (размер);
            - capacity const (размер выделенной памяти);

            - empty const (bool проверка на пустой вектор);

            - push_back копирующий;
            - push_back перемещающий;
            - pop_back с удалением объекта;
            - reserve перевыделяем выделеную память capacity;
            - insert (вставка в произвольную позицию
                проверить capacity,
                переместить элементы к хвосту (начинать с последнего),
                вставка элемента в нужную позицию);
            - erase (удалить элемент из определенной позиции);
            - обмен элементами - тоже можно реализовать;
            - пергрузить оператор << для вывода значений контейнера в консоль.
             
------------------------------------------------------------------------------------------------------------------------------------------------
Проверка контейнера вектор:
    - создание контейнера <int>;
    - добавление 0-9 элементов и вывести на экран;
    - вывести размер контейнера;
    - удалить 3,5,7 элемент из контейнера, вывести результат;
    - добавить значение 10 в начало контейнера, вывести результат;
    - вставить в середину контейнера значение 20, вывести результат;
    - добавить в конец значение 30, вывести результат.

    - pop_back;
    - swap;

2. Подзадача разработать аналог контейнера list.
    Принципт хранения данных - динамический. (работает с кучей, нужно грамотно освобождать ресурсы) Устройство блок памяти Node, у контейнера есть head и tail. "Адресная арифметика" не работает, связь меду node указатели. Освобождать память пройтись по всему списку. 
    
    Преимущества:   - быстрая вставка и удаление (переопределить указатели).
    Недостатки:     - медленный поиск(O(n)).  
    ------------------------------------------------------------------------------------------------------------------------------------------------
    Реализовано в списке двунаправленный:
        - в работе;
        (список из нодов, два направления, prev предыдущий, next следующий и data - значение)
    ------------------------------------------------------------------------------------------------------------------------------------------------
    Реализовано в списке однонаправленный:
        - в работе;
        (список из нодов, одно направление, prev предыдущий и data - значение)
    ------------------------------------------------------------------------------------------------------------------------------------------------
    Проверка контейнера списков:
        - в работе;

    ------------------------------------------------------------------------------------------------------------------------------------------------
